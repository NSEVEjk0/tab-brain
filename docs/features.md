# What you can do in Tab Brain

Tab Brain brings capture, recall, organization, and return visits into one reading library. Each part helps you save useful context and come back to it.

| Feature | How you use it | Why it is useful |
| --- | --- | --- |
| Capture selected Chrome tabs | Open the extension, choose the readable tabs, and save them. | You can keep several sources from the same work session together. |
| Save pasted page text | Choose **Save a page** on the website and paste the title, URL, and text. | You can add material directly from the browser you are using. |
| Close saved tabs | After capture, choose **Close saved tabs** in the extension. | The app confirms the saved records and preserves pinned or changed tabs. |
| Read saved page text | Open a page and expand **Read the saved page text**. | The useful material remains available in your library after the original tab closes. |
| Search the library | Search words from titles, text, excerpts, tags, or your notes. | You can find a page through the detail you remember. |
| Work offline | Open your captured reading and use search, notes, and organization offline. | Your reading stays useful while you are away from a connection. |
| Personal notes | Add your reason for saving a page and choose **Save changes**. | The source keeps the context that matters to you. |
| Topic tags | Edit tags or select a topic to see its pages. | A topic can bring together material from different collections. |
| Collections | Create a collection and add related pages. | You can keep a project, question, or reading plan together. |
| Favorites | Mark a useful page as a favorite. | You have a quick route back to material you use often. |
| Archive and restore | Archive finished work and restore it when you need it again. | You can keep the main library focused while retaining the saved source. |
| Grid, list, and topic views | Choose the view that suits the task. | You can scan page cards, browse a compact list, or explore frequently used tags. |
| Reading status | Mark a page as read or return it to the unread list. | Your reading queue reflects what you have finished. |
| Reminder dates | Choose when you want to revisit a saved page. | An intention to read becomes a scheduled return visit. |
| Return visits | Browse due, upcoming, and unread pages, or move a reminder to tomorrow. | You can choose the next thing to read from one place. |
| Calendar export | Choose **Add to calendar** on a reminder. | You can place the return visit into the calendar you already use. |
| Browser notifications | Enable notifications in Return visits. | The app can alert you when a saved reminder becomes due. |
| Cloud questions | Choose saved sources, review the snippets, and approve a question for Gemini. | You can bring relevant material together for a comparison or research answer. |
| Source previews | Inspect the exact source copy and remove a source before sending. | You control the reading material included in each cloud question. |
| Numbered source links | Follow the source numbers beside the answer. | You can return to the pages behind the comparison. |
| Missing information | Read the answer's section for facts absent from the approved sources. | You can see what to look up next. |
| Model badge and receipt | Watch the request's model badge and view its completed receipt. | The app shows the requested model and the execution location confirmed by the SDK. |
| AI source counter | View the count of source bytes approved for AI requests. | You can keep track of how much source material you have approved. |
| Research brief download | Download a completed answer with its source list. | You can carry the result into your project or meeting. |
| Reading brief preview | Choose bookmarks, short summaries, and reminder dates for a compact brief. | You decide which reading belongs in the copy you want to keep or share. |
| Reading brief download | Preview the copy and choose **Download this brief**. | You can keep a portable reading list, including while offline. |
| Backup and import | Export your saved library and import the file into another browser. | Your pages, notes, collections, and reading plan can move with you. |
| Source and capture date | Open a saved page or answer to see its source and capture time. | You keep the reading connected to where and when it was captured. |
